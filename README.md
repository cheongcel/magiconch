# 🐚 마법의 소라고동 (Magic Conch)

깊은 바다 속에 숨겨진 픽셀 신탁. 소라고동에 손을 얹고 귀를 기울이면, 삶의 사소한 질문에 답을 내려줍니다.

**🔗 Live: [magiconch.onrender.com](https://magiconch.onrender.com)**

---

## 무엇인가요

다마고치 LCD 화면을 오마주한, 순수 HTML/CSS/JS 파일로 만든 웹 입니다. 

## 기능

- **길게 누르기 인터랙션** — 소라고동을 누르고 있으면 금빛 링이 원을 그리며 차오르고, 다 차면 답이 한 글자씩 타이핑되며 나타납니다
- **146가지 답변** — 구체적인 조언부터 예/아니오, 알쏭달쏭한 잠언까지, 인생 해답책처럼 다양하게
- **레어 골든 연출** — 아주 가끔(5%) 화면이 금빛으로 바뀌며 특별한 문구가 나옵니다
- **8비트 효과음** — 외부 음원 파일 없이 Web Audio API로 직접 생성한 사운드
- **정사각 이미지 공유** — 나온 답변을 캔버스로 그려서 네이티브 공유 시트(또는 다운로드)로 바로 공유
- **픽셀 다마고치 비주얼** — 게임보이 4색 그린 팔레트, CRT 스캔라인, 눈 깜빡이는 소라고동 캐릭터

## 기술 스택

Vanilla HTML / CSS / JavaScript 

- Canvas API — 공유용 이미지 렌더링
- Web Audio API — 효과음 생성
- Web Share API — 네이티브 공유 시트 (미지원 환경은 이미지 다운로드로 대체)
